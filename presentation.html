1. Problem Statement & Motivation
Why vision-based relative positioning is indispensable for UAV formations
Overview

The Operational Challenge

  • GNSS Vulnerability: GPS jamming, spoofing, and multipath denial in urban, forest, or contested battlefields leave drones blind to their teammates.
  • RF Inter-Drone Communication Limits: Transmitting positions over WiFi/Radio causes latency, radio bandwidth congestion, and creates an electronic signal beacon.
  • Collision & Drift Hazards: Unregulated aerodynamic wake turbulence and GPS drift can lead to catastrophic mid-air collisions.

Our Vision-Based Solution

  • 100% Passive Sensing: Operates entirely on visual frames from a chase camera; emits zero detectable radio emissions.
  • Real-Time Spatial Telemetry: Extracts 2D centroids, relative bearings, and calculates 3D physical distances (Z, X, Y).
  • Dimensionless Health Engine: Measures nearest-neighbor spacing in normalized drone-widths, enabling zero-calibration formation maintenance.
  • Radar Visualization: Provides a real-time top-down bird's-eye radar map inset for situational awareness.
2. Dataset & Target Drone Specifications
Roboflow Multiple Drones Benchmark Analysis
Dataset Details

Dataset Characteristics

  • Resolution: 640 x 640 RGB test video frames.
  • Test Split: 96 sequential flight frames containing 277 labeled drone instances.
  • Target Drone: 3DR Solo commercial quadcopter with known diagonal motor-to-motor physical width W = 0.46 m.
  • Visual Variations: Fast maneuvering, high/low cloud contrast, overlapping drone occlusions, scale range from 8.4 px (far away) to 154.6 px (close).

Native Frame Dimensions & Calibration

Because the dataset video contains no optical sensor metadata, camera focal length is determined via standard field of view geometry:

f = (W_img / 2) / tan(HFOV / 2)
f = (640 / 2) / tan(30°) ≈ 554.26 px

For custom cameras, our calibration tool (tools/manasvi_distance_viz.py) calculates true focal length from a single known distance measurement.

4. Core Mathematical Formulations
Pinhole 3D reconstruction and formation health metrics
Mathematics

Pinhole Monocular 3D Reconstruction

Z = (f · W) / w
X = (cx - c0) · Z / f
Y = (cy - c0) · Z / f

Where:

  • W = 0.46 m: Physical drone width
  • w = x2 - x1: Bounding box width in pixels
  • f = 554 px: Optical focal length
  • c0 = 320 px: Principal point (optical center)

Calibration-Free Formation Spacing

s = d_px / w_avg (in drone-widths)
w_avg = (w_A + w_B) / 2

Formation Health Classification:

MAINTAINED 3.0 ≤ s ≤ 10.0 drone-widths
TOO CLOSE s < 3.0 drone-widths (Collision Alert)
TOO FAR s > 10.0 drone-widths (Formation Breakdown)

Mathematical Sensitivity Derivation

dZ / dw = - (f · W) / w² = - Z / w
| δZ / Z | = | δw / w |

Physical Finding: Fractional depth error is inversely proportional to detected box width.

  • Near Drone (w = 120 px): 1 px jitter → 0.83% depth error.
  • Far Drone (w = 10 px): 1 px jitter → 10.0% depth error.

Key Failure Modes Identified

  • Out-of-Distribution Urban Clutter (bus.jpg): Tested against a busy Madrid street scene with no drones. The detector fired a false positive (conf = 0.47) on window contours.
  • Morphological Bias (drone.jpg): A white commercial drone in close-up triggered fragmented boxes because the model was trained on dark 3DR Solo frames against open sky.
  • Motion Blur Vulnerability: High angular rates without high shutter speed cause detection loss.
